## Why are the files still called PrismaCore?

So you can switch from PrismaCore without touching your data, settings or server manager setup. See [Compatibility](/ServerCore-7d2d/project/compatibility/) for details.

## Can I go back to PrismaCore?

Only on game 3.2.0 b10, the version PrismaCore 2.5 was built for: stop the server, remove `Mods/ServerCore` and put `Mods/PrismaCore` back. Both use the same data files. PrismaCore isn't updated for game 3.3.

## Something doesn't work the way it did in PrismaCore.

That's a bug. Please [open an issue](https://github.com/gettakaro/ServerCore-7d2d/issues/new/choose) with the command you ran and its output.
